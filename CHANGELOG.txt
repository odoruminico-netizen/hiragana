Hiraganada ver0.3.0

- Full startup rewrite for iPhone Safari.
- Removed optional chaining, nullish coalescing, object spread, arrow functions, destructuring, default parameters, and other newer JavaScript syntax from runtime code.

- New isolated localStorage key: hiraganada-v030.
- Safe startup error screen with recover button.
- Two games: Hiragana Rain and Frog Jump.
- Stage progression, mastery, spaced review, confidence mismatch weighting.
- 50 original algorithmic retro BGM variations using Web Audio.
- Retro tap/correct/wrong/catch/jump/chapter-clear SFX.
- Tiny BGM on/off + next buttons centered at top of game screens.
- 2D pixel frog app icons 180px and 512px.
